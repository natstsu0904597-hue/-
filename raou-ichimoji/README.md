# 羅王の一文字（試作品）

カイザー羅門／羅王占術 公式LINE「無料鑑定お申し込み特典」用のデジタルお守り体験。

## ファイル
- `index.html` … これ1つで動きます（HTML / CSS / JavaScript）。インストールも外部ライブラリも不要。

## 体験の流れ（約30秒）
1. 金の光とともにタイトルが現れる
2. 「縁・進・守・断」から一文字を選ぶ
3. 文字を指でなぞると金色に光る（7割ほどなぞると完成）
4. おりんの鐘が一度鳴り、光が広がり、朱印が押される
5. 羅門の言葉 →「運命に従うな。運命を従えよ。」→ ブランド名
6. 「お守りを保存する」で 1080×1920 の縦長PNGを保存

## 主な仕様
- 鐘の音は Web Audio API でその場で合成しています（外部音源なし＝著作権の心配なし）
- 右上のボタンで消音（設定はその端末に記憶）
- 保存：iPhoneは「写真に保存する」（共有メニュー）または画像の長押し／Android・PCはダウンロードボタン
- なぞれない方向けに、20秒後に「自動で仕上げる」ボタンを表示
- 個人情報の入力・会員登録・外部への送信は一切ありません
- 書体は Google Fonts「しっぽり明朝 B1」（無料・商用可 / SIL Open Font License）

## 公開するときのメモ（今回はまだ公開していません）
- GitHub Pages / Netlify / Cloudflare Pages など無料の静的ホスティングに `index.html` を置くだけで動きます
- LINEの中のブラウザで保存しにくい場合は、URLの末尾に `?openExternalBrowser=1` を付けると Safari / Chrome で開けます
- `index.html` 末尾の `window.__raou = …` は動作確認用です。公開前に消しても問題ありません
